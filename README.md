# romeral-juvenil

Web estática con la temporada del C.D. Fútbol Romeral (3ª Andaluza Juvenil Málaga, Grupo 1): clasificación, resultados y calendario con horarios.

- Site: https://instinct-q0jwr3.github.io/romeral-juvenil/
- Fuente: [RFAF pnfg](https://www.rfaf.es/pnfg/NPcd/NFG_VisCompeticiones_Grupo?cod_primaria=1000123&codequipo=2064582&codgrupo=48465932)
- `bash scripts/run_pass.sh` vuelve a descargar los datos de la RFAF y regenera `docs/`.
